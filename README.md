# Nim game w/ computer && interactive Tutorial

## Nim Tutorial: 
* **Nim** is a mathmetical strategy game with many variations, however this variation has 3 stipulations -

1. There is **one** pile of stones where players each take turns taking from the pile
2. You must take **atleast one stone**, and can optionally take **up to half of the pile size.**
3. The player **who takes the last stone** wins the game

## Features: 
* **Customizable Nim game:** Fully playable Nim with piles (adjustable), turns, run time checks, and computer opponent implemented. 

* **Optimal Computer:** Follows the recursive equation **$3 \times 2^n - 1$** to determine optimal moves to make against the user.
